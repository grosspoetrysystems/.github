# Gross Poetry Systems

*Profoundly unfashionable since 2026.*

Control surfaces for uncertain machines. A small, opinionated collection of tools for agent-era work. Each project stands alone; they share an engineering sensibility, not a system architecture.

## Public work

- **[Poolboy](https://github.com/grosspoetrysystems/poolboy):** portable software documentation, compiled for agents.
- **[OOMPF](https://github.com/grosspoetrysystems/oompf):** share, inspect, and install reproducible OMP profiles.
- **[crooked-pattern](https://github.com/grosspoetrysystems/crooked-pattern):** deterministic agentic-readiness checks for websites and repositories.
- **[rack-mount](https://github.com/grosspoetrysystems/rack-mount-ts):** production-ready project substrate for [TypeScript](https://github.com/grosspoetrysystems/rack-mount-ts) and [Go](https://github.com/grosspoetrysystems/rack-mount-go).
- **[cable-run](https://github.com/grosspoetrysystems/cable-run-ts):** schema, model, and workflow contracts for [TypeScript](https://github.com/grosspoetrysystems/cable-run-ts) and [Go](https://github.com/grosspoetrysystems/cable-run-go).
- **[Newborn Mountain](https://github.com/grosspoetrysystems/newborn-mountain):** stacked pull-request workflows for GitHub.

Everything here is open source. Take what is useful. Leave the rest. Issues and pull requests are welcome.
